# pdstuber.dev
Sources for my personal website, generated by [hugo](https://gohugo.io/), using the [coder](https://github.com/luizdepra/hugo-coder) theme (as a Hugo Module).

## Develop
Needs `hugo` (extended) and `go` (to fetch the theme module).

    hugo server

Update the theme with `hugo mod get -u && hugo mod tidy`.

## Deploy
`fly deploy`. The Dockerfile builds the site with a pinned Hugo image and serves it with [static-web-server](https://static-web-server.net/).
